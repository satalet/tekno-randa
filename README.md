# 🌱 مشروع آثار التكنولوجيا في المجتمع - الصف التاسع الأساسي

مشروع تفاعلي تطبيقي مصمم لدعم منهاج مادة التكنولوجيا (منهاج القدس) للصف التاسع الأساسي.

**إعداد وتصميم الطالبة:** رندة زربا ✨

---

## 🚀 مميزات المنصة التفاعلية
* **لوحة بيانات بيانية حية (Plotly):** مقارنة مرئية دقيقة بين الآثار الإيجابية والمخاطر السلبية للتكنولوجيا في مختلف مجالات الحياة.
* **إدارة ومخاطر النفايات الإلكترونية (E-Waste):** رسوم دائرية وحلول عملية مستدامة للحد من التلوث التقني.
* **مستشار ذكي مدعوم بالذكاء الاصطناعي (Gemini 3.8 Flash):** إمكانية طرح أي سؤال حول المنهج وتلقي إجابات تربوية معتمدة فوراً.

---

## 🛠️ كيفية التشغيل المحلي (Installation)

```bash
git clone https://github.com/satalet/tekno-randa.git
cd tekno-randa
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
